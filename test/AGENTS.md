# 测试执行约束

- 只跑当前改动影响的测试文件；有必要时再用名称筛选。先说明范围，不顺带跑全量、截图脚本或整套视觉验收。
- 成功默认零截图。只有用户明确要求人工视觉验收时才启用 `SUPER_BAODAN_TEST_SCREENSHOTS=visual`；常规验证不得开启。
- 浏览器准备优先复用 `helpers/browser-scenario.mjs`。失败截图由共享辅助代码处理，每个场景每次执行最多一张，限临时诊断目录，不写入 `docs`。
- 不为截图增加等待或改变功能断言；截图异常不得掩盖原始失败。不要无目的地重复读取页面快照。
- `agent.snapshot`、`snapshotRequired` 等是会话状态同步机制，不是图片。其竞态测试，以及退出、数据写入、路径安全测试不得因精简截图被删除。
- 迁移旧验收用例时，记录独有断言的新归属；只有已有行为测试覆盖的重复部分才可删除。不为减少文件数合并无关场景。
- 使用隔离数据；不安装依赖，不调用付费模型，不通过修改产品行为让测试通过。
