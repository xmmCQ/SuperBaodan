## 安装与使用

支持 Windows 10 1809 或更新版本的 64 位系统，首次安装需要联网。

1. 下载并运行 **`SuperBaodan.exe`**，按提示完成安装。
2. 从开始菜单或桌面快捷方式打开“超级宝蛋”。
3. 在助手设置中登录模型账号或填写 API Key，选择模型。模型使用可能需要订阅或接口额度。
4. 按需添加工作区、工作软件、文档入口和常用 Skill。

默认安装目录为 `%LOCALAPPDATA%\Programs\SuperBaodan`。工作台在浏览器中打开，地址为 `http://127.0.0.1:3212`。

### 更新与卸载

个人数据保存在 `%LOCALAPPDATA%\SuperBaodan`。更新前请备份数据，点击页面中的“退出工作台”，再运行新版安装包。

卸载默认保留个人数据。勾选“同时删除本软件的个人数据和登录信息”并确认后，会删除待办、记录、会话、配置、登录信息及默认工作区文件。**删除不可恢复，请先备份。** 外部工作文件夹保持不变，浏览器中的页面偏好可单独清除。

## 产品功能

### 日历与待办

- 查看工作日历、当日安排、遗留工作和持续工作。
- 新增、编辑、完成和删除待办，支持多行内容、计划日期、截止日期及周期事项。
- 拖动待办改期，调整当日卡片顺序。
- 显示节假日与调休标识，供日程安排参考，单位排班以所在单位通知为准。

### 每日记录

- 按日期保存会议纪要和工作记录，支持 Markdown 和历史搜索。
- 调整记录顺序，将选中的内容交给宝蛋整理。
- 保存前自动备份，同时修改时提示冲突。

### 智能助手

- 首页直接对话，展开助手查看完整聊天、思考和执行过程。
- 支持流式回答、图片输入、表格、代码块、复制和引用追问。
- 管理历史会话，搜索对话正文，通过目录定位提问和回复；回复小节支持折叠并记住展开状态。
- 停止任务、压缩上下文；任务结束后继续处理追加消息。

![展开后的智能助手](docs/screenshots/assistant.png)

### 工作区与文件

- 管理多个工作区，分别保存对话历史。
- 浏览、搜索和上传文件，预览文本、Markdown、代码、图片和 PDF。
- 通过文件标签切换预览，调整面板宽度和阅读布局。
- 输入 `@文件名` 引用工作区文件，查看本轮涉及和修改的文件。

### 工作文档

- 从首页打开分类目录，集中收藏本地文件和在线文档。
- 浏览本地文件或粘贴路径、网址，自定义名称，按分类搜索和排序。
- 下载导入模板，从 Markdown 批量导入分类和链接；导入前可编辑名称、分类和地址，跳过重复项。
- 删除入口默认保留源文件；开启对应选项后，可同时将本地源文件移入回收站。

### 工作软件

- 管理最多 20 个本机程序或快捷方式，选择一键打开的软件及启动顺序。
- 支持单独启动，已识别为运行中的软件自动跳过。

### 模型、提示词与 Skill

- 搜索和选择模型，设置新对话默认模型、思考等级及可见范围；悬停可查看完整模型名称。
- 支持 ChatGPT Plus/Pro（Codex）等账号登录、API Key 和自定义模型配置。

![模型配置界面](docs/screenshots/model-settings.png)

- 在设置中编辑项目提示词，保存后用于当前会话的下一次提问。

![项目提示词管理界面](docs/screenshots/project-prompt.png)

- 按项目、全局和只读来源查看 Skill，支持搜索、安装、更新、卸载及自定义编辑。
- 本地自定义 Skill 可在项目与全局之间迁移，迁移时保留备份。
- 使用固定提示词和扩展快捷命令，保存聊天字号与正文宽度偏好。
