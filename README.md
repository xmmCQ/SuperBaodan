# 超级宝蛋

面向个人工作的 Windows 工作台，将日历、待办、每日记录、工作软件和智能助手集中在一个页面中。

## 部署方式

### 方式一：在线安装包

适合希望直接安装使用、不想手动配置运行环境的用户。

**运行要求**

- Windows 10 1809 或更新版本的 64 位系统。
- 可访问 `nodejs.org` 和 `registry.npmjs.org` 的网络。
- 用于显示工作台的浏览器。

**安装步骤**

1. 运行取得的 EXE 在线安装包。
2. 选择安装目录，按提示完成安装。安装器会下载 Node.js 24.15.0 和 Pi 0.84.4 及其依赖，可能需要数分钟。
3. 安装完成后，通过“超级宝蛋（在线版）”快捷方式启动。
4. 在助手中配置自己的账号、模型和工作区。

无需手动执行安装命令，不需要 WSL，也不需要全局安装 Node.js 或 Pi。运行环境放在安装目录中，不永久修改系统 PATH；工作台仍在默认浏览器中显示。

在线安装版默认访问地址为 `http://127.0.0.1:3212`。它使用独立的快捷方式和数据目录，不覆盖原有源码版。

首次使用不预填制作人的工作软件、固定提示词、账号、Skill、待办或历史会话。工作软件和固定提示词列表默认为空，由用户自行添加。

安装包下载入口以 [GitHub Releases](https://github.com/xmmCQ/SuperBaodan/releases) 的实际附件为准。EXE、ZIP 和 GitHub 自动生成的 Source code 压缩包不是同一种部署方式；若尚无 EXE 附件，可使用下方的源码部署方式。私有仓库中的附件需要登录有访问权限的 GitHub 账号才能下载。

未签名的安装包可能被 Windows 标记为“未知发布者”，请只运行可信来源的文件。下载失败时检查网络或代理设置后重试，安装日志位于 `%LOCALAPPDATA%\SuperBaodan\installer`。

### 方式二：源码或 ZIP 部署

适合已有 Node.js、Pi，或需要自行维护源码的用户。

**准备环境**

安装 Windows Node.js 22.19 或以上版本，再安装 Pi：

```powershell
npm.cmd install -g --ignore-scripts @earendil-works/pi-coding-agent@0.84.4
```

项目目录不需要再执行 `npm install`。

**获取并启动**

使用 Git 克隆到有写入权限的目录，例如：

```powershell
git clone https://github.com/xmmCQ/SuperBaodan.git 'D:\Apps\SuperBaodan'
cd 'D:\Apps\SuperBaodan'
.\start.cmd
```

也可以下载 ZIP，完整解压后双击 `start.cmd`。不要直接在压缩包内运行。首次启动会创建空白待办文件，已有文件不会被覆盖。

此方式默认访问地址为 `http://127.0.0.1:3211`，使用本机已安装的 Pi。若需要桌面快捷方式，执行一次：

```powershell
powershell -ExecutionPolicy Bypass -File 'D:\Apps\SuperBaodan\install-shortcut.ps1'
```

安装位置不同时，将命令中的路径替换为实际目录。若 Pi 不在默认的全局 npm 安装目录，可通过环境变量 `SUPER_BAODAN_PI_PACKAGE` 指定其包目录。

### 首次配置

- **账号与模型**：在助手设置中登录支持的账号，或填写供应商 API Key；选择默认模型和思考等级。使用模型可能需要相应订阅或接口额度。
- **工作区**：添加允许助手处理的本机目录。不同工作区分别管理对话历史。
- **工作软件**：从首页“打开工作软件”下拉菜单进入“管理软件”，添加程序或快捷方式路径，选择参与一键打开的软件。
- **Skill 与固定提示词**：按需安装 Skill、创建自定义 Skill，或配置首页常用提示词。

在线安装版不会复制源码版的 Pi 登录信息。两种部署方式如需迁移数据，应由用户自行备份并迁移，不会自动读取对方的数据目录。

### 数据保存与更新

| 内容 | 在线安装版 | 源码或 ZIP 版 |
|---|---|---|
| 待办、记录、会话、软件配置及备份 | `%LOCALAPPDATA%\SuperBaodan\data` | 项目目录下的 `data` |
| 默认工作区 | `%LOCALAPPDATA%\SuperBaodan\workspace` | 项目目录下的 `workspace` |
| Pi 账号与模型配置 | `%LOCALAPPDATA%\SuperBaodan\pi\agent` | `%USERPROFILE%\.pi\agent` |
| 默认访问端口 | `3212` | `3211` |

以上为默认路径，源码版可通过环境变量调整。数据目录中主要包括：

- `work-todo.md`：工作待办。
- `daily-records.json`：每日记录。
- `work-apps.json`：保存后的工作软件配置。
- `vskills.json`：首页固定提示词。
- `sessions`：历史对话。
- `backups`：本地备份。

待办和每日记录由各工作区共享，对话历史按工作区区分。模型 API Key、登录令牌及部分模型配置可能包含敏感信息，请勿提交到源码仓库或打入分发包。

**更新前**，通过页面“退出工作台”关闭服务，并备份数据、工作区及 Pi 用户配置。

- **在线安装版**：运行新版本安装包，升级默认沿用已登记的安装目录；旧安装目录或目标目录仍有程序运行时，先退出对应工作台再继续。属于安装版的快捷方式随升级更新，同名源码版入口保持不变。用户数据单独保存，更新及默认卸载不删除个人数据。
- **ZIP 版**：覆盖程序文件，保留已有 `data` 和 `workspace`，然后重新启动。
- **Git 版**：本地没有待提交修改时，执行以下命令：

```powershell
cd 'D:\Apps\SuperBaodan'
git switch main
git pull --ff-only origin main
.\start.cmd
```

助手默认空闲 10 分钟后休眠，再次使用时恢复会话，工作台页面仍可使用。启动异常可查看对应数据目录下的 `server-error.log`。

## 产品功能

以下为当前源码支持的功能，安装包以对应发布版本为准。

### 日历与待办

- 日历和每日内容独立加载，不等待智能体准备完成；数据读取失败时可直接重试。

- 查看工作日历、当日安排，以及遗留工作和持续工作列表。
- 新增、编辑、完成和删除待办，支持多行内容、计划日期、截止日期及周期事项。
- 拖动待办改期，调整当日卡片显示顺序。
- 显示中国大陆节假日和调休标识。数据来自第三方整理，仅供日程参考，不代表单位排班。

### 每日记录

- 按日期保存会议纪要和工作记录，支持 Markdown。
- 通过日历和历史搜索查找记录，调整当日记录顺序。
- 将选中的记录交给宝蛋整理。
- 写入前备份，遇到同时修改导致的版本冲突时提示处理。

### 智能助手

- 在首页直接对话，或展开完整助手；两处共用模型、账号和思考等级。
- 流式显示回答，支持 Markdown、表格、代码块和图片输入。
- 图片支持 PNG、JPEG、WebP、GIF，最多4张，单张不超过5 MiB、合计不超过10 MiB；超限会在发送前提示，明确发送失败时恢复原附件并保留新草稿。
- 新建、切换、重命名和删除会话，搜索历史标题与对话正文。
- 复制回复、复制代码块，引用选中文字在当前对话追问。
- 通过对话目录定位提问及回复标题，快速回到最新消息。
- 折叠查看思考与工具执行过程，显示任务运行、重试、停止、失败及完成状态。
- 停止任务、压缩上下文，在当前任务完成后处理追加消息；连接中断后自动尝试恢复对话显示。

### 工作区与文件

- 添加、搜索、切换、重命名和移除本机工作区，恢复各工作区的最后会话。
- 浏览文件树、搜索文件名、上传文件，选择同名文件覆盖或跳过。
- 预览文本、Markdown、代码、图片和 PDF，通过标签切换已打开文件。
- 调整会话栏和文件面板宽度，放大预览或折叠文件树。
- 输入 `@文件名` 引用当前工作区文件，查看本轮涉及及已确认修改的文件。

### 工作软件

- 在界面中添加、编辑、删除软件，无需修改启动脚本。
- 支持最多 20 个本机 `.exe` 程序或 `.lnk` 快捷方式。
- 勾选参与一键打开的软件，调整启动顺序，也可单独启动。
- 能识别已运行的软件时跳过重复启动；单个程序路径错误不影响其他程序。

### 模型、提示词与 Skill

- 按供应商搜索和选择模型，管理默认模型、思考等级及可见模型范围。
- 支持 ChatGPT Plus/Pro（Codex）等 OAuth 登录、供应商 API Key 和自定义模型配置。
- 在“设置 → 项目提示词”中编辑当前工作区根目录的 `AGENTS.md`，不同项目分别保存，不修改全局提示词。
- 项目提示词保存后重载当前会话，下一次提问使用新内容；保留对话记录，提供备份、冲突提示和未保存提醒。执行中的任务需先结束或停止。
- 按项目、全局和只读来源查看 Skill，支持搜索、安装、更新、卸载及自动调用显隐。
- 创建、编辑和删除本地自定义 Skill，使用 Prompt Templates 和扩展快捷命令。
- 在首页配置固定提示词，一键发起常用任务。
- 调整聊天字号和正文宽度，在本机浏览器保存阅读偏好。
